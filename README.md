
# Program Menghitung Total Belanja (Python)

Program sederhana berbasis CLI (Command Line Interface) menggunakan bahasa pemrograman Python untuk menghitung total harga belanjaan berdasarkan nama barang, harga satuan, dan jumlah pembelian, serta menghitung uang kembalian.

## Fitur
- Input dinamis berdasarkan jumlah jenis barang.
- Perhitungan subtotal otomatis per barang.
- Menghitung total keseluruhan belanja.
- Fitur pembayaran dan perhitungan uang kembalian.
- Penanganan error sederhana (`try-except`) jika terjadi kesalahan input.

## Cara Menjalankan
1. Pastikan komputer Anda sudah terinstal Python.
2. Clone repository ini atau unduh file `main.py`.
3. Buka terminal atau command prompt pada direktori file tersebut.
4. Jalankan perintah berikut:
   ```bash
   python main.py
